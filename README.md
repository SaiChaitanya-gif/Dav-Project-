\# 🌦️ Weather Data Analysis Using Python



\## 📌 Project Overview



This project focuses on analyzing weather data using Python libraries such as NumPy, Pandas, Matplotlib, and Seaborn.



The main objective is to clean, analyze, and visualize weather data to identify patterns and understand relationships between different weather conditions.



This project demonstrates practical Data Analytics skills, including data preprocessing, exploratory data analysis (EDA), statistical analysis, and data visualization.



\## 🎯 Project Objectives



\- Understand and explore the weather dataset.

\- Identify and handle missing values.

\- Remove duplicate records.

\- Perform statistical analysis.

\- Analyze temperature, humidity, wind speed, and visibility.

\- Visualize weather patterns and distributions.

\- Identify correlations between numerical variables.

\## 📊 Project Workflow



\### 1. Import Libraries

Imported the required Python libraries:

\- NumPy

\- Pandas

\- Matplotlib

\- Seaborn



\### 2. Load Dataset

\- Loaded the weather dataset using Pandas.

\- Displayed the first five records.

\- Displayed the last five records.

\- Displayed random records.



\### 3. Exploratory Data Analysis (EDA)

\- Checked dataset dimensions.

\- Examined column data types.

\- Used `info()` to understand dataset structure.

\- Generated statistical summaries using `describe()`.

\- Checked missing values.

\- Identified duplicate records.



\### 4. Data Cleaning

\- Created a backup of the original dataset.

\- Removed duplicate records.

\- Handled missing numerical values using median.

\- Handled missing categorical values using mode.

\- Removed unnecessary spaces from column names.

\- Verified the cleaned dataset.



\### 5. Data Analysis Using NumPy and Pandas



Performed the following analyses:



\- Average temperature.

\- Maximum temperature.

\- Minimum temperature.

\- Average humidity.

\- Average wind speed.

\- Average visibility.

\- Weather condition frequency.

\- Temperature category frequency.



\### 6. Data Visualization



Created the following visualizations:



1\. Temperature Distribution – Histogram.

2\. Temperature Trend Over Time – Line Plot.

4\. Temperature vs Humidity – Scatter Plot.
